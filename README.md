# ManuFlow — дизайн

Макеты платформы научного журнала: подача статей, автопроверка, слепое рецензирование и библиотека.

- **Главная страница:** https://yamy-me.github.io/manuflow-design/
- **Кабинеты автора, рецензента и редактора (14 экранов):** https://yamy-me.github.io/manuflow-design/app.html

Это статичные макеты. Рабочий сайт на Django лежит в репозитории проекта.
